**VS Code + Emmet — Aprende a programar más rápido**

Descubre Visual Studio Code y Emmet con tutoriales, capturas y ejemplos prácticos.

Guía paso a paso · Nivel principiante · Ejemplos HTML

### 3. Cómo pondría la teoría y las capturas

Seguiría siempre esta estructura: **explicación corta → pasos → captura → resultado**.

Ejemplo: **Cómo instalar una extensión**.

Las extensiones son complementos que añaden funcionalidades a Visual Studio Code, como soporte para lenguajes, formateadores o herramientas de desarrollo.

**Paso 1.** Abre Extensions desde la barra de actividad o con `Ctrl+Shift+X`.

**Paso 2.** Busca la extensión. Comprueba quién la publica y revisa su descripción antes de instalarla.

**Paso 3.** Selecciona la extensión y pulsa **Install**.

**¿Qué hemos aprendido?** Ahora sabemos encontrar, comprobar e instalar extensiones para adaptar VS Code a nuestras necesidades.

Utilizaría capturas hechas por el grupo, con flechas o números que señalen dónde pulsar. No pondría una captura por cada clic: unas **2 o 3 por tutorial** cuando ayuden a entenderlo.

### 4. Cómo haría la parte de Emmet

En lugar de poner únicamente capturas, mostraría **la abreviatura y el HTML generado uno al lado del otro**. Así se entiende mejor qué hace Emmet.

Se podría incluir un ejemplo interactivo en el que el visitante seleccione un operador, vea la abreviatura y observe el código HTML generado, acompañado de una captura real de VS Code.

### 5. Qué capturas haría primero

Prepararía las capturas iniciales de instalación, interfaz, creación de archivos, configuración, extensiones y expansión de Emmet. *(La respuesta original mostraba un bloque visual de “Capturas pendientes” sin una lista detallada visible.)*

### 6. Cómo repartiría el trabajo entre los tres

Una persona podría preparar la teoría de VS Code y las capturas de instalación e interfaz; otra, las extensiones, configuración y revisión de las explicaciones; y la tercera, Emmet, los ejemplos y la demostración final.

Después, los tres revisarían la web, comprobarían las capturas, trabajarían en las skills y documentarían las decisiones con IA.

### 7. Un detalle para que no se os olvide

La página con capturas sería el **producto principal**, pero la profesora también exige `PROCESO.md`, las conversaciones con IA, una skill pública analizada, una skill propia probada y las fuentes. Estos documentos pueden quedar en el repositorio de GitHub sin llenar la web didáctica con toda esa documentación.

**Propuesta final:** hacer una web que parezca un pequeño curso de VS Code y Emmet, con explicaciones breves, tutoriales ilustrados y ejemplos que el visitante pueda copiar y probar.

**Pregunta para decidir el diseño:** ¿una sola página larga con menú que lleve a cada apartado, o una página de inicio y varias páginas separadas? Para un trabajo de 2–3 sesiones, elegiría la primera por ser más sencilla de crear y mantener.
