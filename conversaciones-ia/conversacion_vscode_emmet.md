# Proyecto de Puesta en Producción: VS Code y Emmet

He revisado los tres documentos que has compartido: el enunciado de la profesora, los apuntes de Visual Studio Code y la chuleta de Emmet.

Te propongo una **primera versión del proyecto centrada en las ideas más importantes**, para que puedas llevarla a tu grupo, compararla con las propuestas de tus compañeros y decidir entre los tres qué incluir en la web.

La profesora pide entre **5 y 7 ideas clave**, un glosario de al menos 5 términos y una demostración práctica. Por eso he seleccionado 7 ideas que cubren los dos temas sin meter información secundaria.

## 1. Las 7 ideas principales que propongo

1. **¿Qué es Visual Studio Code y para qué sirve?** Explicar que es un editor de código gratuito, multiplataforma y ampliable mediante extensiones. Diferenciar brevemente un editor de un IDE. Prioridad: imprescindible para introducir el tema.
2. **Interfaz y organización de proyectos.** Enseñar el Explorador de archivos, editor, barra de actividad, panel inferior y barra de estado. Explicar por qué conviene abrir una carpeta de proyecto completa. Prioridad: imprescindible para aprender a manejarlo.
3. **Herramientas de edición y atajos.** Presentar la paleta de comandos, IntelliSense, búsqueda y reemplazo, formateo de código y atajos como `Ctrl+S`, `Ctrl+F` y `Ctrl+Shift+P`. Prioridad: alta, porque demuestra cómo trabajar más rápido.
4. **Extensiones y personalización.** Explicar qué son las extensiones, cómo instalarlas desde Marketplace y para qué sirven. Incluir la diferencia entre configuración de usuario y del proyecto. Prioridad: alta, porque forma parte del bloque asignado.
5. **¿Qué es Emmet y qué ventajas tiene?** Explicar que permite generar código HTML mediante abreviaturas, evitando escribir manualmente estructuras repetitivas. Mostrar cómo se expande una abreviatura en VS Code. Prioridad: imprescindible, es la segunda mitad del tema.
6. **Operadores fundamentales de Emmet.** Explicar los símbolos `.`, `#`, `>`, `+`, `*`, `{}`, `[]`, `()` y `$`, con ejemplos sencillos y comprensibles. Prioridad: imprescindible, es el contenido práctico central.
7. **Combinar VS Code y Emmet en un proyecto real.** Mostrar cómo crear la estructura de una página HTML, generar listas o menús con Emmet y editar el resultado en VS Code. Prioridad: imprescindible para conectar teoría y práctica.

## 2. Demostración práctica que llevaría al grupo

Mi propuesta es hacer una **miniweb de videojuegos con Emmet**, porque es un ejemplo visual, sencillo y fácil de comprobar.

**Abreviatura de Emmet:**

```text
section.juegos>(article.juego$>h2{Juego $}+p{Descripción del juego})*3
```

Al expandirla en VS Code se genera una sección con tres artículos, cada uno con su título y descripción. El ejemplo se ilustró con una representación visual de tres tarjetas llamadas Juego 1, Juego 2 y Juego 3. Los estilos de las tarjetas se añadirían después con CSS.

Este ejemplo permite enseñar a la vez clases, elementos hijos, elementos hermanos, repetición, texto y numeración.
